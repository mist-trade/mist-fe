## 2. 详细设计

### 2.1 全局顶栏 (`app/components/layout/AppHeader.tsx`)
- **注入位置**：`app/layout.tsx` 的 `<ThemeProvider>` 之内、`{children}` 之上，全站唯一常驻。
- **导航链路 (Navigation Links)**：
  - `/dashboard`：组合监控（`📊 组合监控`）
  - `/k`：K线看盘（`📈 K线看盘`）
  - `/chan`：双级别缠论（`⚡ 双级别缠论`）
  - `/strategies`：策略工坊（`🧠 策略工坊`）
  - `/backtests`：回测复盘（`🎯 回测复盘`）
  - `/settings/realtime-subscriptions`：实时订阅（`📡 实时订阅`）
- **状态与工具 (Right Controls)**：
  - **市场状态时钟**：显示上海时间 `HH:mm:ss` 及当前交易时段状态（盘前集合竞价 09:15~09:25、开盘中 09:30~11:30 / 13:00~15:00、已收盘）；
  - **主题切换**：支持浅色（Light）与深色（Dark）一键无缝切换。

### 2.2 工作台基架 (`app/components/layout/WorkspaceShell.tsx`)
- **公理契约**：
  - **左侧（Sidebar）**：决定当前屏幕要观察什么对象。放置标的搜索、股票池、配置表单、历史记录等。
  - **右侧（Main Content）**：核心可视化与操作对象。放置图表、单步推演控制器、多标的标签页与明细表。
- **折叠交互 (Collapsible)**：
  - 展开状态：宽度 `300px`；
  - 折叠状态：宽度 `48px`（仅显示展开触发把手或精简图标）；
  - 状态持久化：可通过 localStorage 记住用户在不同页面的折叠偏好；
  - 动画：CSS `transition: width 0.2s ease`，折叠时图表自适应 resize。

### 2.3 业务页面对齐改造规范
1. **`/backtests`**：
   - 移除私有 `<header>`，直接作为 `WorkspaceShell` 的标准示范应用；
   - 左侧为 `BacktestConfigPanel` + `BacktestRunHistory`；
   - 右侧为多标的 Tabs + `BacktestReplayBar` + `TradingViewChart` + `BacktestSignalTable`。
2. **`/k`**：
   - 移除私有 `<header>`；
   - 提取自选与标的搜索至左侧边栏；
   - 右侧顶部仅保留周期、数据源快速切换与 K 线大画布。
3. **`/chan`**：
   - 移除挤在 Header 里的标的与日期搜索，收敛入左侧边栏；
   - 右侧顶部保留 30m/5m 联动胶囊，获得最大的上下双图可视高度。
4. **`/strategies`**：
   - 移除私有 `<header>`；
   - 策略列表入驻左侧标准边栏，右侧统一 Tab 主体。
